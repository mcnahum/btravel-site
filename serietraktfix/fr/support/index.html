Assistance

Comment pouvons-nous vous aider ?

Pour obtenir de l’aide avec SerieTraktFix, poser une question, transmettre un commentaire ou effectuer une demande relative à vos données, contactez directement le développeur.

Contact

E-mail : btravel@e-nahum.net
Développeur : Marc Nahum
Localisation : Suisse

Avant de contacter l’assistance

  • Vérifiez que votre appareil Apple et SerieTraktFix sont à jour.
  • Dans l’application, ouvrez Réglages et consultez le diagnostic après avoir reproduit le problème.
  • Indiquez le type d’appareil concerné et décrivez brièvement le problème. Ne transmettez jamais votre jeton Trakt, votre code d’autorisation ou d’autres identifiants.

Compte et données

SerieTraktFix utilise votre compte Trakt uniquement après votre autorisation. Vous pouvez retirer l’autorisation depuis les réglages de votre compte Trakt. Les données locales et les sauvegardes de l’application peuvent être supprimées depuis votre appareil.

Délai de réponse

Les demandes d’assistance sont généralement examinées sous cinq jours ouvrables.
